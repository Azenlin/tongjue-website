## 起點：學長問我，有沒有個人網站？

中秋連假開始前，清大學長余文皓顧問跟我說，他想把我的個人資歷放到他們團隊的網站上。問題是，我當時只有一個用 WordPress 做的一頁式公司網站，內容很陽春，上面也沒有所謂的個人經歷。於是余顧問很自然地問我：「那有沒有辦法做一個個人網站？」

我看過余顧問自己的網站，做得非常好；他在課程裡用的簡報，也都是用 Claude 做的，每一份都很漂亮。我就開始想：不如趁這次機會，學著用 Claude Code 把公司官網整個改版一次，把我的個人經歷也放上去。

## 先認識工具：Claude Design 與 Artifacts

這次我是從 Claude Design 開始的。先補充一個背景：Claude Design 原本是一個獨立的網站，做出來的東西都存在另一個系統上；就在我決定改版官網前一週（9 月 16 日），一次改版把 Claude Design 整合進了 Claude 裡。現在用 Claude Design 做的東西，不論是 Design System、文件（docs）、簡報（Slides）還是網頁（Web），全部都能在 Claude 的 Artifacts 裡找到。

這個改變很關鍵：**Claude Code 可以直接讀取 Artifacts 裡的內容**。設計和開發不再是兩套分開的系統，在 Claude Design 裡調好的設計稿，Claude Code 可以直接接手，轉成真正的網站。

## 第一步：先有自己的主視覺

我認為做公司網站，第一件事是要有自己的主視覺。

我的 Logo 是先請 ChatGPT 從公司名稱開始發想的。公司叫「銅爵」，銅爵是古代的一匹千里馬，所以我腦海裡自然浮現的畫面是「中國」、「古代」和「馬」。這三個元素結合在一起，就成了一張白色宣紙上，蓋著一枚馬頭印章——這就是銅爵 Logo 的由來。

顏色我選了偏暗的紅，因為不想讓紅色太刺眼、太鮮豔。這個暗紅色，後來就成了整個品牌的主色調。

### 什麼是 Design System？為什麼它很重要？

Design System（設計系統）可以想成品牌的「視覺規則手冊」：主色是哪一種紅、標題用什麼字型和大小、內文行距多少、按鈕長什麼樣子、卡片的圓角和陰影怎麼設定……全部寫成固定的規則。

它的價值在於「一致」。沒有 Design System 的時候，每請 AI 做一次東西，它都可能給你新的配色、新的字型，做十份就有十種風格；有了 Design System，之後不管做網頁、簡報還是任何 Artifacts，都能直接沿用同一套規則，讓所有產出看起來都出自同一個品牌。對一人公司來說，這就像身邊多了一位永遠記得品牌規範的設計師。

## 第二步：想清楚網站要說什麼

有了 Design System，我開始用它製作新的公司官網。網站架構並不是一步到位，我先設想自己想呈現哪些東西：

1. **個人經歷**：這一頁一定要有，我希望讓人先認識我這個人。
2. **服務內容**：告訴大家我在做什麼、可以幫上什麼忙。
3. **案例分享**：用我實際做過的案子，讓大家看到 AIOS 可以用在哪些場合。
4. **部落格**：也就是網站上的「我的觀點」，我會定期分享自己的想法與觀點，還有工作上用到的工具。

有了這個大架構之後，底下的子分頁才慢慢長出來。我會一邊看、一邊想每一頁還要補充什麼才會更完整。像是服務內容，最後就收斂成三個類別：AI 知識庫建置、AI 導入與數位轉型、淨零碳規劃與 ESG。我會思考哪些服務項目可以整合在一起，不需要列出一張太過繁瑣的清單。

## 第三步：先在 Artifacts 做初版，不要急著寫網頁

這是我最想分享的一個做法：**不要一開始就讓 Claude Code 直接生成網頁檔案（也就是 HTML 這類程式碼），而是先請它在 Artifacts 裡建一個初版的設計稿。**

這樣做的好處是，很多簡單的調整——例如修改一段文字——可以直接在 Artifacts 裡手動處理，不必每次都透過 Claude Code。這比直接改網站快得多，也省下不少 token。等設計稿確定了，再請 Claude Code 把它轉成真正的網站。

## Claude 能做的，比我想像的多太多

建站過程中，我發現 Claude 能做到的事情，遠遠超出我的想像：

- **互動圖表**：文章裡的數據可以做成讀者能點、能操作的互動圖表，這點讓我非常驚豔。
- **會探出頭的小貓咪**：網站右下角的 LINE 圖示，我請 Claude 加了一隻會探出頭跟讀者打招呼的小貓咪，沒想到它真的做得出來。
- **自己客製的預約表單**：過去在 WordPress 上，表單功能得付費才能用。這次 Claude Code 直接用 Google Apps Script 幫我客製了一個：讀者送出表單後，資料會自動存進 Google 試算表，同時寄通知信給我，完全不用付費外掛。
- **hover 效果**：hover 指的是滑鼠移到某個元素上方（還沒點下去）時，畫面產生的變化，例如卡片微微浮起、按鈕換色、圖片放大。網站上加了許多這樣的小互動，讓整個網站看起來更活潑。

## 從設計稿到真的上線

設計稿做完，還有最後一哩路：讓全世界連得到。這一段對我來說完全是陌生領域，DNS、名稱伺服器、DNSSEC，每個名詞都是第一次碰。

我的網域原本就在 Hostinger 註冊，這次沒有更動，只把網址的管理（DNS）交給 Cloudflare，網站本身也放在 Cloudflare 的免費方案上，主機費是 0 元。Claude Code 一步一步帶著我操作，而且在動手之前，先幫我查好哪些設定跟公司信箱有關、絕對不能動。網站上線後，公司信箱照常收發，完全沒有中斷。

上線之後，它還帶著我把 SEO 的基本功一次做完：把網站登錄到 Google Search Console 和 Bing，讓搜尋引擎找得到；產生網站地圖，告訴搜尋引擎網站有哪些頁面；還幫每一頁設定分享縮圖，也就是把連結貼到 LINE 或 Facebook 時，自動出現的那張預覽圖。

## 真正的關鍵：AI 早就認識我了

這次改版能這麼順，還有一個很少人會注意到的原因：Claude Code 並不是從零開始認識我。

這幾個月來，我一直把工作上的會議、閱讀、決策，以及自己的經歷，整理進一套知識庫，也就是我說的 AIOS。我拿過哪些證照、細節是什麼，我的學歷、過去的工作經驗，全部都已經在裡面了。所以寫個人經歷這一塊時，我不需要再從頭交代一次，Claude Code 直接到我的知識庫裡查找；它也從我過去寫過的文章裡，理解我的寫作偏好與風格，再用我自己的經驗，幫我打造這次的網站。

這正是我一直想說明的：**知識保留，對工作來說非常重要。** 多數人用 AI 的方式，是每次把資料上傳給它、用完就結束，下一次又要重新交代一遍。但如果你平常就把經驗、決策和素材留下來，放在一個 AI 可以自己去搜尋的工作空間裡，你累積得越多，AI 能幫你的就越多。

## 代價：兩天燒掉一週 60% 的 token

當然，這一切也有代價。

我全程使用 Opus 5.5 模型、推理強度設為 High 來製作網站。因為擔心 Claude Code 沒辦法延續我的想法，我一直不敢關掉對話（session），結果上下文（context）變得超級長，我記得至少被壓縮了四、五次。兩天下來，一週 7 天的 token 額度就被我燒掉了 60%（我目前是使用 Claude Pro 方案，月繳約 600 台幣）。這是我使用 Claude Code 將近半年以來，從來沒有發生過的事。

<TokenBar />

事後回頭看，教訓很清楚：一件事開一個新的對話，修改意見盡量整理好一次給。至於擔心 AI「忘記前面講過什麼」，真正的解法不是死守同一段對話，而是把重要的背景和決定寫進知識庫——這也正是 AIOS 在做的事。

## 讓網站不像 AI 做的：挑剔，是人的工作

我認為，對美感的挑剔，是這次能完成公司官網很大的關鍵。

現在很多人都用 AI 做網站，但常常一眼就看得出是 AI 生成的，因為有太多小細節會露出痕跡：

- **圖片**：直接拿 AI 生成的圖當封面，圖裡卻明顯有 AI 幻覺。有美感的人會挑剔，請 AI 重新生成一版比較自然的，至少要做到連自己都看不出來。選照片時我也一樣挑剔，例如會嫌圖裡的人不像台灣人，或是「沒有人開會這麼開心的啦」，最後乾脆自己去選。
- **用詞**：AI 寫的句子如果沒有順過，乍看之下文縐縐、好像很有深度，但仔細琢磨，這種看似有深度的句子反而會造成閱讀障礙。像「1995 年，會用 Excel 是加分」這種邏輯怪怪的句子，我讀不懂，就一定要改。個人頁的文字也是先讓 AI 寫一版，我再改；有一段它改寫完，我的回覆是：「你寫得沒有我好，直接使用我的文字。」
- **版面**：AI 沒有眼睛，沒辦法逐一幫你檢查網站哪裡不平衡、哪裡的間距過大、段落有沒有壓到圖。它偶爾會出一些小失誤，例如刪掉一個按鈕區塊之後，沒有重新調整版面，留下一大塊空白。這些都必須靠你一一挑出來修正。

AI 讓「試試看」的成本變得很低，所以我可以看到實際畫面再決定要不要，而不是只憑想像。但最後拍板的，一定是人。

## 對網站有偏執的人，Claude Code 是最好的工具

像我這個網站，如果要交給別人做，我認為至少需要一到兩個月的來回討論才有可能完成，而且我一定不會滿意。因為我想調整的東西太多了，對方很可能在某個時間點表示已經做完、沒辦法再改，除非加錢；最後我終究會因為預算考量而妥協收手。

Claude Code 讓你不必妥協。你可以不斷修正、再修正，直到自己滿意為止。所以我認為，對官網、對網站製作有所偏執的人來說，Claude Code 是現在做網站最好的工具。
